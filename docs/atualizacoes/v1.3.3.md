# Versão 1.3.3

Cartão de boas-vindas na primeira abertura.

## Resumo

- [NOVO] Boas-vindas da primeira abertura (ITEM-19): ao abrir o programa pela primeira vez, um cartão explica o projeto e convida a avaliar no GitHub e no perfil da Adge no Google.
- [NOVO] Janela principal e configurações (ITEM-20): em Configurações → Sobre, o botão "Ver a apresentação do projeto" reabre o cartão quando quiser.

## Detalhes

### Boas-vindas da primeira abertura (ITEM-19)

**O que mudou:** o cartão aparece uma única vez e explica que o programa é uma iniciativa sem fins lucrativos da Adge, feita para ajudar contadores e auxiliares de contabilidade no dia a dia sem custo por funções básicas, e para resolver problemas de pequenas empresas de forma gratuita. Também deixa claro que tudo roda só no computador do usuário e convida a contribuir com uma avaliação no GitHub ou no Google. Se houver versão nova, o aviso de atualização só abre depois que o cartão for fechado, para as janelas não se sobreporem.
**Por que:** quem instala o programa precisa saber, logo de início, o que ele é, quem está por trás e como ajudar a mantê-lo, já que a única "contrapartida" pedida é uma avaliação.

### Janela principal e configurações (ITEM-20)

**O que mudou:** Configurações → Sobre ganhou o botão "Ver a apresentação do projeto".
**Por que:** o cartão aparece só uma vez; o botão permite rever a mensagem e acessar os links de avaliação depois.
