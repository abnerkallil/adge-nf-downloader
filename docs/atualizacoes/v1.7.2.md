# Versão 1.7.2

A verificação de atualização deixa de dizer "versão mais recente" quando o GitHub não respondeu.

## Resumo

- [CORREÇÃO] Atualização do programa (ITEM-14): quando o GitHub recusa a consulta (por exemplo, limite de consultas), o programa avisa que não conseguiu verificar, em vez de informar que já está na versão mais recente.

## Detalhes

### Atualização do programa (ITEM-14)

**O que mudou:** respostas diferentes de "sem Release" (404), como o limite de consultas do GitHub (403/429) ou erro do servidor, passam a ser tratadas como falha na verificação. A verificação automática não conta mais o dia como já checado nesses casos e tenta de novo na próxima abertura.

**Por que:** antes, o limite do GitHub era confundido com "sem novidade", e o programa podia ficar sem avisar uma versão nova por um dia inteiro.
